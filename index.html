Mission Briefing

⚡ Quick Crash Course

CRISPR is a real-world scientific tool that acts like tiny molecular scissors. It can go into DNA, find a mutation causing a problem, and cut it out!

How the game works:

  • 🛑 Step 1: The Anchor (PAM Sequence). The scissors can't cut unless they lock on. Find the code CC_ in the DNA and click the FIRST 'C'.
  • 🔑 Step 2: The Secret Key (Guide RNA). Once anchored, the scissors need instructions. Translate the color-coded DNA mutation into an RNA key using the provided cheat sheet.
